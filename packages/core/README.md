# `cyberpsychosis-core`

Deterministic emergent gameplay kernel middleware:
- `DeterministicECS` with property clamping and full snapshot cloning
- `VocabularyRegistry`, `GrammarMatcher`, `SemanticsExecutor` (Five-Dimensional Framework)
- `RuleEngine` (Baba-Is-You style Rule-as-Entity runtime recompilation & Restricted DSL)
- `MultiModalSpatialIndex` (`Grid2D` + `Continuous2D` + `GraphTopology`)
- `CausalTracker` (First-class Causal Lineage DAG)
- `EmergenceKernel` (Fixed-tick deterministic scheduler, Time-Travel `rewindTo`, and `forkAndPredict` parallel WorldFork)
