# `cyberpsychosis` — All-in-One Emergent Gameplay Engine SDK & CLI

`cyberpsychosis` is the unified entry package for the **Cyberpsychosis** emergent gameplay engine middleware. It re-exports `cyberpsychosis-core`, `cyberpsychosis-plugins`, `cyberpsychosis-demo`, `cyberpsychosis-tui`, and `cyberpsychosis-web`, and provides the `cyberpsychosis` CLI binary.

## Quick Usage

```bash
# Run the automated cross-domain emergence showcase & Causal DAG trace in terminal
npx cyberpsychosis demo

# Launch the interactive Web Visual Workbench on http://localhost:4173
npx cyberpsychosis web
```
